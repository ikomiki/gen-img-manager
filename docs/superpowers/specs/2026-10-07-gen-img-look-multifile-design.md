# GenImgLook 複数ファイル表示・ドラッグ&ドロップ 設計

## 目的

Quick Look が使えない（`2026-10-07-gen-img-look-design.md` 参照）ことを補うため、GenImgLook でファイルを手早く切り替えられるようにする。

- 画像ファイルをウィンドウにドラッグ&ドロップして、表示内容を切り替える。
- 複数ファイルを同時に開いたら、プレビュー.app と同じく1ウィンドウにまとめ、左サイドバーのリストとキー操作で切り替える。

## 前提・制約

- 対象は PNG のみ。フォルダや PNG 以外のファイルは無視する。
- 既存の解析部分（`Shared/Parsing/`）と `PreviewView` / `MetadataPanel` はそのまま使う。
- キー操作は、修飾キーが完全に一致するとき（修飾キーなし）だけ反応させる。

## ウィンドウ管理

`DocumentGroup` をやめ、`AppDelegate`（`NSApplicationDelegateAdaptor`）が `NSWindow` を作る。中身は `NSHostingController` で SwiftUI のビューを載せ、`sceneBridgingOptions = [.title, .toolbars]` でタイトルとツールバーを SwiftUI 側から設定する。

| きっかけ | 挙動 |
|---|---|
| Finder で開く、Dock のアイコンへドロップ（`application(_:open:)`） | 渡された PNG を1つのウィンドウにまとめる。ウィンドウが既にあっても新しいウィンドウを作る |
| 「ファイル > 開く…」（Cmd+O） | `NSOpenPanel`（複数選択可、PNG のみ）で選んだファイルを新しいウィンドウで開く |
| ファイルなしで起動 | 空のウィンドウを1つ出す |
| Dock のアイコンをクリック（表示中のウィンドウが無いとき） | 空のウィンドウを1つ出す |

- 空のウィンドウには「PNG をここにドロップ」と「開く…」ボタンを表示する。
- 渡されたファイルに PNG が1つも無い場合は、ウィンドウを作らない（ウィンドウが1つも無ければ空のウィンドウを出す）。
- 新しいウィンドウは、直前のウィンドウから少しずらして（cascade）配置する。
- 「設定…」メニューは出さない。

## ファイルリスト（`FileList`）

UI から切り離した値型にし、ユニットテストする。

- 生成時に、PNG（`UTType.png` に適合）でディレクトリでないファイルだけを残し、ファイル名の自然順（`localizedStandardCompare`）に並べる。1つも残らなければ生成しない（`nil`）。
- 現在位置は先頭から始まる。
- 移動: 前・次（端では止まる）、先頭、末尾、指定 URL の選択。

## 画面

- **左サイドバー:** ファイルが2つ以上のときだけ表示する。幅は約180pt。各項目はサムネイル（`QLThumbnailGenerator` で非同期生成）とファイル名。クリックで表示を切り替える。
- **中央と右:** 画像と右サイドパネルは既存の `PreviewView` のまま。ファイルを切り替えると、テキストの最大化は解除される。
- **タイトルバー:** 表示中のファイル名。空のウィンドウでは「GenImgLook」。
- **ツールバー:** 共有・「プレビューで開く」（表示中のファイルが対象。空のウィンドウでは出さない）、サイドパネル開閉。
- **読み込み:** 表示中のファイルが変わるたびに、画像とメタデータをメインスレッド外で読み込む。読み込み中は直前の表示を残す（最初の1枚はインジケータを出す）。画像を読めなければ「開けません」を表示する。

## ドラッグ&ドロップ

- ウィンドウにファイルをドロップすると、PNG が1つ以上あればリストをそれで置き換えて先頭を表示する。
- PNG が1つも無ければドロップを受け付けない（表示は変わらない）。

## キー操作

| キー（修飾キーなし） | 動作 |
|---|---|
| ↑ / ← | 前のファイル（先頭では止まる） |
| ↓ / → | 次のファイル（末尾では止まる） |
| Home | 先頭のファイル |
| End | 末尾のファイル |
| Esc | ウィンドウを閉じる |

Space ではウィンドウを閉じない（従来の Space で閉じる動作は廃止する）。

## テスト

- XCTest で `FileList` を検証する: PNG の振り分け（フォルダ・PNG 以外の除外）、自然順の並び、PNG が無いときの `nil`、前・次・先頭・末尾の移動と端での停止、URL の選択。
- ウィンドウの開き方、ドラッグ&ドロップ、サムネイル、キー操作は実機で手動確認する。

## 範囲外

リストからファイルを外す操作、フォルダの展開、PNG 以外の形式、リストの端での折り返し、タイトルへの位置（n/m）表示。
