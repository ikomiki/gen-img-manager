# docs/ ドキュメント執筆ガイド

このディレクトリの操作説明書・使用方法ガイドは **`docs/usage.html` を共通トーン（体裁・文体）の基準**とします。新規の HTML ドキュメントは、このファイルのトーンに合わせて作成してください。迷ったら `usage.html` を開いて倣うこと。

## トーン（文体）

- **日本語・です／ます調**。簡潔で技術的。冗長な前置きや感情的表現は避け、操作と事実を淡々と書く。
- **実例駆動**。コマンドは実行例とともに示し、期待される標準出力や補足は `.dim`（muted）で併記する。
- **制約に正直**であること。`--dry-run` の意味、必須キー、「何を壊さないか／何を skip するか／冪等か」を明記する。憶測の手順を書かない。
- コマンド名・引数・オプション・出力は**実コードと一致**させる。挙動が変わったらドキュメントも更新する。

## 体裁（自己完結 HTML）

- **単一ファイルの自己完結 HTML**。外部 CSS/JS に依存せず、`<style>` をインラインで持つ。`<html lang="ja">` / `<meta charset="utf-8">` / viewport を入れる。
- HTMLドキュメントを作成するときは必ず DESIGN.md を参照する

## 構成（usage.html に倣う）

1. `<div class="layout">` の中に、左固定の `<nav>`（セクションへのリンク一覧）と `<main>`。
2. `<header class="hero">`：`.stars`（★の装飾）→ `<h1>`（先頭に `<span class="en">` で英字ラベル）→ 導入の `<p>`。
3. **番号付き `<h2>` セクション**。見出し先頭に `<span class="no">` で連番（`01`／`02`…）を置く。セクション構成はガイド対象に応じて決める。
4. 補足は `.note` ボックス、手順の列挙は `.steps`（`<ol class="steps">`。CSS counter で丸数字）、並列比較は `.cols`（2カラム）、スクリーンショットは `figure.shot` ＋ `figcaption`。
5. 構造的な参照は `<table>`（構文／対象／挙動など）。キー表記は `<kbd>`。
6. `<footer>`：バージョン等の一行の注記。

## コンポーネント（共通 CSS クラス）

| クラス                                        | 用途                                              |
| ---------------------------------------------- | -------------------------------------------------- |
| `.note`                                        | 補足ボックス。先頭に `<span class="t">` でラベル。 |
| `.steps`                                       | 手順の番号付きリスト（CSS counter で丸数字）。     |
| `.cols`                                        | 2カラムの並列表示（比較表など）。                  |
| `figure.shot`                                  | スクリーンショット。`figcaption` で説明を添える。  |
| `.hero` / `.stars` / `.en`                     | ヘッダー装飾（★の連続・英字ラベル）。              |
| `kbd`                                          | キーボードキーの表記。                             |
| `.dim`                                         | 補助説明文（muted 相当）。                         |
| `pre` / `code`                                 | コマンド・コード表示。                             |
| `<h2>`（下線＋アクセント）/ `<h3>`（小見出し） | 見出し階層。                                       |
