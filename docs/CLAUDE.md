# docs/ ドキュメント執筆ガイド

このディレクトリの操作説明書・使用方法ガイドは **`docs/master-import-usage.html` を共通トーン（体裁・文体）の基準**とします。新規の HTML ドキュメントは、このファイルのトーンに合わせて作成してください。迷ったら `master-import-usage.html` を開いて倣うこと。

## トーン（文体）

- **日本語・です／ます調**。簡潔で技術的。冗長な前置きや感情的表現は避け、操作と事実を淡々と書く。
- **実例駆動**。コマンドは実行例とともに示し、期待される標準出力を `<span class="c">`（muted）のコメント行で併記する。
- **制約に正直**であること。`--dry-run` の意味、必須キー、「何を壊さないか／何を skip するか／冪等か」を明記する。憶測の手順を書かない。
- コマンド名・引数・オプション・出力は**実コードと一致**させる（CLI は `apps/cli/src/index.ts`）。挙動が変わったらドキュメントも更新する。

## 体裁（自己完結 HTML）

- **単一ファイルの自己完結 HTML**。外部 CSS/JS に依存せず、`<style>` をインラインで持つ。`<html lang="ja">` / `<meta charset="utf-8">` / viewport を入れる。
- HTMLドキュメントを作成するときは必ず DESIGN.md を参照する

## 構成（master-import-usage.html に倣う）

1. `<header>`：`<h1>` タイトル ＋ `<p class="sub">` 副題（対象 CLI／パッケージ名を `<code>` で）。
2. 導入段落 → 必要なら `.note`（青・補足）／`.warn`（黄・注意）ボックス。
3. パイプラインがあれば `.flow`（`.step` → `.arrow` → `.step`）で図示。最終段の `.step b` をアクセントにする。
4. **番号付き `<h2>` セクション**（例: `1. 前提` / `2. セットアップ` / `3. コマンド` / `4. 投入されるテーブルと列` / `5. 動作` / `6. よくある操作`）。
5. 構造的な参照は `<table>`（ファイル／列／挙動など）。
6. `<footer>`：関連する設計書・実装計画への参照（`docs/superpowers/specs/...` / `docs/superpowers/plans/...` のパスを `<code>` で）。

## コンポーネント（共通 CSS クラス）

| クラス                                 | 用途                                                               |
| -------------------------------------- | ------------------------------------------------------------------ |
| `.note`                                | 補足・前提（青）。先頭に `<strong>` でラベル。                     |
| `.warn`                                | 注意・破壊的操作の警告（黄）。                                     |
| `.flow` / `.step` / `.arrow`           | 処理の流れ。`.step b` でアクセント色。                             |
| `pre` / `code`                         | コマンド・コード。コード内コメントは `<span class="c">`（muted）。 |
| `.muted`                               | 補助説明文。                                                       |
| `.pill`                                | 小さなラベル（任意）。                                             |
| `<h2>`（下線付き）/ `<h3>`（小見出し） | 見出し階層。                                                       |

## 公開後の手順

- 新規 HTML を追加したら、**`docs/index.html` のカードリンク（`.cards` 内の `a.card`）を手動で追加**する（索引は静的記述）。
- ドキュメントどうしは相対パスでリンクする（例: `./master-import-usage.html`）。
