GEN-IMG-MANAGER WEB VIEWER — USAGEgen-img-manager web ビューア 使い方

LAN 内のブラウザから画像ライブラリを閲覧する（gim-server）。

01できること／できないこと

できる

  • 一覧・検索・絞り込み（履歴付き）
  • 並び替え
  • ディレクトリ選択
  • 全画面ビューア
  • スライドショー

できない（デスクトップ版で行う）

  • 詳細メタデータ表示
  • レーティング設定
  • ディレクトリのスキャン登録
  • タグ分析
NOTElibrary.db は読み取り専用で開くので、web 側の操作でライブラリが変わることはありません。
WARN認証はありません。LAN 内での利用を前提としているので、インターネットへ直接公開しないでください。

02前提

  • デスクトップ版を一度起動して library.db を作っておくこと（サーバはマイグレーションを実行しません）。
  • 画像と DB がある Mac 上でサーバを起動し、同じ LAN のブラウザから接続します。

03起動

pnpm -C web build          # web フロントをビルド（同梱される）
cargo build --release -p gim-server
./target/release/gim-server

標準出力の例（LAN アドレスが取得できたとき）:

http://192.168.1.23:5180 で待受中
データディレクトリ: /Users/you/Library/Application Support/com.technonet.genimgmanager

LAN アドレスが取得できない場合は1行目が ポート 5180 で待受中 になります。

04コマンドラインオプション

オプション既定値意味
--host0.0.0.0待受アドレス
--port5180待受ポート
--data-dir~/Library/Application Support/com.technonet.genimgmanagerlibrary.db と thumbnails/ を含むディレクトリ
--allow-hostなし（複数回指定可）DNSリバインディング対策で追加許可するホスト名
NOTEIPアドレス・localhost・.local で終わる名前は常に許可されます。社内DNSの独自名でアクセスするときだけ --allow-host を指定してください。

05操作

タッチ操作

操作動作

2本指で広げる・縮めるズーム（最大6倍）
ズーム中に1本指で動かす表示位置を動かす（画像の四辺まで）

06検索とフィルタ

クエリ文字列はデスクトップ版と同じ記法です。フィルタシートで作った条件もクエリ文字列に反映されるので、手で直すこともできます。

NOTE検索履歴はブラウザの localStorage に最大50件保存されます。クエリ入力をタップすると開き、入力中の文字列で前方一致絞り込みされます。

トークン

トークン対象種類
prompt:positive プロンプト全文検索
negative:negative プロンプト全文検索
model:モデル名全文検索
filename:ファイル名全文検索
tool:生成ツール（a1111 / comfyui）部分一致
sampler:サンプラー名部分一致
rating:レーティング数値（範囲・集合可）
width: height: pixels:画像サイズ数値
steps: seed:生成パラメータ数値
created: modified:日付日付範囲

上記以外の名前は素の全文検索語として扱われます。

記法

rating:>=4 width:>=1024 steps:20..40
created:2025-01-01..2025-01-02 rating:none,1,3
-blurry -sampler:euler forest OR mountain
記法意味例
>= <= > <比較rating:>=4
A..B範囲（両端を含む。日付は A の 0:00:00 〜 B の 23:59:59）steps:20..40 / created:2025-01-01..2025-01-02
1,3,5集合（いずれか）rating:none,1,3
none未設定（NULL）を含めるrating:none
-除外（NOT）-blurry / -sampler:euler
OROR 結合（大文字）forest OR mountain
"..."フレーズ一致prompt:"best quality"

07スライドショー

  • ビューア下部の ▶ から間隔（3 / 5 / 10 / 30 秒）・ループ・シャッフルを設定して再生します。
  • 再生対象は検索結果全体です。
  • 設定はブラウザごとに保存されます。

08うまくいかないとき

症状対処
起動時に「デスクトップ版を一度起動してから、もう一度実行してください。」と出る--data-dir が違うか、library.db が無い。デスクトップ版を起動して作る
ブラウザに「web フロントがビルドされていません」と出るpnpm -C web build のあと cargo build --release -p gim-server をやり直す
「Host ヘッダ … からのアクセスは許可されていません」と出る独自のDNS名でアクセスしている。--allow-host <名前> を付けて起動する
画像が出ず枠だけ残る元ファイルが消えている（404）か、外部ドライブが切れている（503）。次へ送れば止まらない
スマホで表示が遅い初回はリサイズ生成が走る。2回目以降は web-cache/ から返る
